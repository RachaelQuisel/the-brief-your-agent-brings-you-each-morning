# The Morning Brief

A workshop from the Soft Fork podcast.

This repo holds the full package for one episode:

- `workshop.md` - the workshop teaching plan
- `handout.md` - the printable handout
- `snips/` - the day's research snips, with the sources and their links
- `transcript.txt` - the episode transcript
- `EPISODE.md` - the episode title and its live audio link (the MP3 is too large to store here)

Based on: "Soft Fork - October 22, 2026".
